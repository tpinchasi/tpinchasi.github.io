# tpinchasi.github.io

The website of IFocus, an Android app: its home page and privacy policy,
served by GitHub Pages at https://tpinchasi.github.io/.

- `index.html`: the home page, in English and Hebrew.
- `privacy.html`: the privacy policy, made from the app's `PRIVACY.md`:

      python3 tools/privacy.py ../transcript/perfect-spouse/PRIVACY.md

- `style.css`, `rubik.ttf` (the app's font, SIL Open Font License), the icons.

Nothing on the site loads from other servers.
